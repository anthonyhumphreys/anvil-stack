# Anvil Raycast Extension

Internal Raycast extension for controlling the Anvil desktop companion API.

Extension identifier: `dev.anthonyhumphreys.anvil.raycast`.

## Setup

1. In Anvil, open Settings -> Devices & system -> Mobile Companion.
2. Enable Mobile Companion.
3. Create a Raycast token.
4. In Raycast, import this extension folder and set:
   - Companion Base URL
   - Companion Token

## Commands

- Overview: workspace, approvals, sessions, and recent threads.
- Approvals: approve, approve for session, or decline pending Codex requests.
- Chats: send input to active Codex sessions.
- Launch Workflow: start a status sweep, review, missing-test hunt, ship handoff, or custom prompt.
- Open Desktop App: focus the desktop app.
