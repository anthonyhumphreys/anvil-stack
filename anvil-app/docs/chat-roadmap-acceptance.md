# Chat interaction roadmap acceptance

This checklist records the six approved chat workstreams and the current verification boundary. The replay preview and its event data are synthetic. Automated tests exercise the production history conversion, turn composition, execution topology, and small pure helpers; they do not establish provider delivery, real scroll behavior, or visual performance.

| #   | Acceptance                                                                                                                                                                                                                                                             | Fixture or verification                                                                                                                                                                                        | Remaining check                                                                                                                                                                                                         |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Guide, queue, and side questions are capability-gated and describe delivery truthfully. A side question remains separate from the active task.                                                                                                                         | Composer intent tests and the replay's local capability-gated actions.                                                                                                                                         | With live Codex and an ACP provider, verify available actions match advertised capabilities, each request is delivered or queued once, rejection preserves the draft, and the side thread does not steer the task.      |
| 2   | Streaming keeps code gutters and image frames stable and retains the last valid Mermaid and document previews through incomplete updates and recovery; retry does not duplicate a request; draft, reading position, and selection survive updates and thread switches. | Partial event replay, reconnect/thread-switch fixture, stream-preview unit tests, composer intent tests, and scroll-position unit tests.                                                                       | Manually interrupt and reconnect a live stream. Confirm the last valid preview remains visible, retry is idempotent, and draft, text selection, per-thread scroll position, and jump-to-latest behavior remain correct. |
| 3   | Evidence-backed run outcomes are separated from task delivery/completion state.                                                                                                                                                                                        | Synthetic outcome derivation tests and existing transcript rendering.                                                                                                                                          | Verify success, failure, interruption, and unresolved-input cases against real provider events; confirm a delivered follow-up is never described as completed work.                                                     |

The reference host metadata provided for this work is Mac15,13, Apple M3, 16 GiB RAM. The host-info script can capture system values, but neither that metadata nor the fixture's live counters are a performance result. Codex, Claude, t3code, and Anvil task-benchmark trials remain unmeasured until each is run with the shared protocol.
